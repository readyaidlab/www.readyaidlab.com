## 디자인 (2026-11-12 개편)
원래 홈페이지의 배경색·글꼴(Pretendard)·자간·메뉴·첫 화면 구성·문구를 그대로 쓰고, 페이지마다 내용을 그대로 보여주는 입자 모션그래픽을 더했습니다.
첫 화면(제목 "Making everyone Ready to aid."의 모든 글자를 수만 개의 점으로 그림. 옅은 점이 줄마다 모여 글자가 되고, 이후 "Ready"에만 점의 진하기가 왼쪽에서 오른쪽으로 5초에 한 번 파동처럼 지나감. 제목의 위치·크기·색은 원래와 같음) · Mission(여러 사람 → 쓰러진 사람과 위치 핀 → 무릎 꿇고 키트로 처치, 아래 "누구나 → 현장에서 → 바로 처치"가 차례로 강조) · Pre-ER(골든타임이 줄어드는 20분 타임라인과 늦게 도착하는 구급차) · Thesis(심정지 → AED 충격 → 심박) · Why(사람마다 다른 결과 → 시스템을 거쳐 같은 결과) · 검정 바탕 4개의 축 요약 · Ready(포장 개봉 → 꺼내기 → 처치 시작, 0~30초 막대가 차오르며 단계가 켜짐) · Aid(가이드라인 체크리스트) · Certain(배터리 없음 → 기어) · Guided(게이지 바늘이 정상 구간에 멈추고 체크) · Contact(편지가 봉투에 들어가 닫히고 날아감).
기기 대응: 아이폰 SE~Pro Max, 갤럭시 S·A·Z 플립·Z 폴드(접힘·펼침, 가로·세로), 아이패드 mini~Pro 13, 갤럭시 탭 S9·Ultra 화면 크기로 점검(가로 넘침 없음, 태블릿·가로 화면에서도 제목 3줄 유지). 제목 점 개수는 기기의 제목 크기와 CPU에 맞춰 자동 조절.
WebGL을 쓸 수 없는 기기에서는 그래픽 없이 문구만 표시됩니다. 개편 전 파일은 GitHub 이력(커밋 35c53c0)에 있습니다.

## 내용 수정
GitHub에서 index.html 또는 en.html을 열고 연필 아이콘으로 문구를 수정합니다. 별도 빌드나 패키지 설치가 필요 없습니다. 언어별 내용은 자동 번역·동기화되지 않으므로 양쪽 파일을 함께 검토하세요.
색·여백·글꼴은 assets/site.css, 모션그래픽은 assets/field.js에서 변경합니다. 이 두 파일을 고치면 두 HTML 하단·상단의 ?v= 값을 함께 올려 브라우저 캐시를 갱신하세요. 이메일 변경 시 표시 문구와 mailto 링크도 함께 바꿉니다.

## 배포와 확인
이 저장소의 main 브랜치는 기존 Vercel Production 배포에 사용되어 왔습니다. main 수정은 운영 사이트에 반영될 수 있으므로 미리보기 브랜치에서 먼저 확인하는 방식을 권장합니다.
커밋 후 GitHub의 Deployments → Production과 Vercel 배포 상태를 확인하고, 실제 한국어·영문 URL, KO/EN, 모바일 메뉴, 이메일 링크를 검증하세요. 성공한 커밋만으로 실제 도메인 반영이 검증되는 것은 아닙니다.
